Connect API
Enter your broker API credentials below. These are stored securely and used only for historical data and backtesting.
📖 How to get your API credentials ▼
1. Login to your broker's developer/API portal
2. Create a new app — choose "Trading" type
3. Copy the API Key and API Secret
4. Generate an access token via OAuth (Zerodha: use "Token" button in dashboard)
5. Paste all three values below and click Connect
🔒 How are my API keys used? ▼
✓ API keys are stored encrypted in a local SQLite database
✓ Keys are NEVER shared, logged, or sent to any third-party server
✓ Keys are only used to fetch historical candle data from your broker
✓ You retain full ownership and control of your broker account
✓ You can revoke API access from your broker portal at any time
✓ Quantly does NOT place live trades without your explicit permission
⚠ Disclaimer: By connecting your broker API, you authorize Quantly to read historical market data and account information using your credentials. Quantly does NOT automatically place trades. All backtesting is simulation only. Past performance does not guarantee future results. Use at your own risk. Not financial advice.
